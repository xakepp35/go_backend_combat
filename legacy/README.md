# Исторические материалы

Каталог `2026-10-19` — побайтовый архив состояния до переработки, включая два локальных SQL-черновика владельца. `SHA256.json` содержит контрольные суммы оригиналов. Файлы внутри архива не исправляются; ссылки старого курса могут быть неактуальны.

Действующая программа и навигация находятся в [корневом README](../README.md). Исторические примеры не являются требованиями нового курса.
