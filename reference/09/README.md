# Неделя 09: На моей машине работает. А на твоей?

Это открытая версия после практики недели 09. Сравни со своей попыткой и объясни различия. Основной проект веди в одном своём репозитории; новые версии здесь нужны для сравнения.

[Урок](../../student/09_ENVIRONMENT.md) · [ДЗ](../../combat/09_ENVIRONMENT.md)

Запуск из этой папки: `go run ./cmd/jobflow`. С недели 10 это сервер, остановка Ctrl+C.

Проверки из корня курса: `python3 tools/coursecheck.py --lesson 9 --project reference/09`.

## Контейнерное окружение

`docker compose run --rm --build app` запускает CLI; `docker compose up -d --wait postgres` — базу. Обычная остановка `docker compose down` сохраняет именованный том. [Окружение](../../docs/ENVIRONMENT.md).

Модель и общие ошибки живут в pkg. Минимальный CLI работает напрямую с memory; полный сервисный договор (ctx, req) → (res, err) смотри в examples/hexagonal, не выводи его из приватных помощников ранних недель.
