# Этап 01: открытый пример после практики

После двух изменений требований осталось два дела. Исходный список и его правки описываются в заметке ученика; здесь показана итоговая версия. Измени порядок и сравни с новым ожиданием.

Запуск из этой папки: `go run .`. Модуль уже создан; `go mod init` повторять не нужно. Для работы веди один собственный репозиторий: снимки нужны для сравнения и разбора.

[Урок](../../student/01_FIRST_PROGRAM.md) · [ДЗ](../../combat/01_FIRST_PROGRAM.md) · [Проверки и границы их покрытия](../../checks/README.md)

Открытые проверки запускаются ментором из корня курса: `python3 tools/coursecheck.py --lesson 1 --project reference/01`. Они покрывают прежний минимальный контракт этапа; новые сценарии из ДЗ до расширения автоматизации разбираются по таблице примеров и на ревью. В этом этапе переработки новые автотесты не добавлялись.
