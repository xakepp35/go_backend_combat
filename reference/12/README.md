# Неделя 12: Закрыли программу. Куда делись данные?

Это открытая версия после практики недели 12. Сравни со своей попыткой и объясни различия. Основной проект веди в одном своём репозитории; новые версии здесь нужны для сравнения.

[Урок](../../student/12_SQL.md) · [ДЗ](../../combat/12_SQL.md)

Запуск из этой папки: `go run ./cmd/jobflow`. С недели 10 это сервер, остановка Ctrl+C.

PostgreSQL запускается в Compose; SQL упражнений выполняем в jobflow_lab. Приложение пока на map, встроенный Goose подключится на 14. [Памятка](../../docs/POSTGRES.md).

Проверки из корня курса: `python3 tools/coursecheck.py --lesson 12 --project reference/12`.

## Контейнерное окружение

`docker compose up -d --build app` запускает HTTP-приложение; `docker compose up -d --wait postgres` — базу для будущего SQL. До 14 задачи приложения ещё в памяти. Обычная остановка `docker compose down` сохраняет именованный том. [Окружение](../../docs/ENVIRONMENT.md).

## Task-контракты

Модель, ошибки, DTO и интерфейсы в pkg. api.New принимает pkg.TaskService, app.New — pkg.TaskRepository. Публичные операции (ctx,req) → (res,err), ответ списка — объект. HTTP v1 кодирует res.Tasks как массив; прежние клиенты не требуют изменения. Приватные SQL/map-помощники не являются публичным портом. Фоновые Job с 20 сохраняют свою прежнюю реализацию до отдельного этапа.
