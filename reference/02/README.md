# Этап 02: открытый пример после практики

Здесь реализована обязательная практика с тремя делами, двумя перерывами и бюджетом вечера. В уроке сначала разбирается сокращённый пример на двух длительностях. Контрольный итог этого снимка: 85 минут, план помещается в 90.

Запуск из этой папки: `go run .`. Модуль уже создан; `go mod init` повторять не нужно. Для работы веди один собственный репозиторий: снимки нужны для сравнения и разбора.

[Урок](../../student/02_VALUES.md) · [ДЗ](../../combat/02_VALUES.md) · [Проверки и границы их покрытия](../../checks/README.md)

Открытые проверки запускаются ментором из корня курса: `python3 tools/coursecheck.py --lesson 2 --project reference/02`. Они покрывают прежний минимальный контракт этапа; новые сценарии из ДЗ до расширения автоматизации разбираются по таблице примеров и на ревью. В этом этапе переработки новые автотесты не добавлялись.
