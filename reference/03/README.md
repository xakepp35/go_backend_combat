# Этап 03: открытый пример после практики

Сохраняем расчёт трёх дел, добавляем защиту входа и вывод напоминаний. Значения для экспериментов меняются в начале main. Это модель решения о напоминании, без реального ожидания по времени.

Запуск из этой папки: `go run .`. Модуль уже создан; `go mod init` повторять не нужно. Для работы веди один собственный репозиторий: снимки нужны для сравнения и разбора.

[Урок](../../student/03_DECISIONS.md) · [ДЗ](../../combat/03_DECISIONS.md) · [Проверки и границы их покрытия](../../checks/README.md)

Открытые проверки запускаются ментором из корня курса: `python3 tools/coursecheck.py --lesson 3 --project reference/03`. Они покрывают прежний минимальный контракт этапа; новые сценарии из ДЗ до расширения автоматизации разбираются по таблице примеров и на ревью. В этом этапе переработки новые автотесты не добавлялись.
