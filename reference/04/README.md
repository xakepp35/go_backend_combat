# Этап 04: открытый пример после практики

Расчёт, проверка, форматирование и вывод разделены на функции в plan.go. В сравнении с этапом 03 отдельно добавлена карточка через describe: при своём рефакторинге сначала сохрани поведение, затем оформляй эту новую строку отдельным изменением.

Запуск из этой папки: `go run .`. Модуль уже создан; `go mod init` повторять не нужно. Для работы веди один собственный репозиторий: снимки нужны для сравнения и разбора.
