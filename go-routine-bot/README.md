# go-routine-bot

**Go + routine + bot: учимся писать на Go и находим ритм, который помещается в жизнь.**

Telegram-бот и Mini App для ученика и ментора. Помогает выбрать следующий посильный шаг, получить поддержку, сдать работу и увидеть подтверждённый прогресс.

> Открываешь кабинет после работы. В нём — одна понятная задача, материалы, критерий готовности и кнопка «Нужен разбор». Завтра можно продолжить с того места, где остановился.

**Статус на 6 ноября 2026:** оформлены продуктовые документы и техническое задание. Приложение ещё предстоит разработать; описанные возможности — требования к MVP.

## Что уже согласовано

- Название и каталог: **go-routine-bot**.
- Пилот: один ментор и первые участники. Возможно подключение ещё 2–3 человек; состав уточняется.
- Личный кабинет: **Telegram Mini App**; бот ведёт диалог и доставляет уведомления.
- Три маршрута по цели: **Старт в backend / Переход на Go / Системное проектирование**.
- Для участника, переходящего на Go, разработка бота может стать основным учебным проектом.
- Предлагаемый ритм: два подхода по 45–60 минут в неделю и короткий разбор; расписание согласуется с участником.
- ИИ помогает разобраться в материале. Обязательную работу и понимание принимает ментор.
- Стек MVP: один Go-сервис, PostgreSQL, pgxpool/v5, встроенный Goose/v3, Docker Compose.

## Первый полезный результат

Ученик открывает Mini App, видит свой небольшой шаг и начинает его. После перезапуска прогресс остаётся. Следующее приращение — сдача результата, ответ ментора и следующий шаг.

На этой основе постепенно появляются помощь, напоминания, повторение и аттестации. [Этапы и готовность каждого приращения](ROADMAP.md).

## Связь с курсом

Бот использует материалы [Go Backend Combat](../README.md), [исходные вопросы интервью](../interview/README.md) и плакаты. Ментор превращает выбранный материал в небольшие задания и критерии готовности.

Связь задаётся устойчивыми идентификаторами и версиями материалов. Номера и названия глав могут меняться при переработке курса. Конкретные существующие опоры перечислены в [пилоте](PILOT.md).

Публикация бота, создание Telegram-аккаунта, подключение платного API и отправка личных приглашений в этот пакет документации не входят.
