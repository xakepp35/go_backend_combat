# Учимся отвечать, пока учимся писать

Все [500 исходных вопросов](README.md) сохранены вместе с подсказками и ответами. Здесь выбираем подходящие к пройденному.

В начале хватит двух-трёх вопросов. На следующих темах берём четыре-шесть и возвращаемся к двум старым. Если в списке этой недели вопрос повторился, дай новый пример вместо повторения заученной фразы. Некоторые недели начинают с повторения: в исходном банке нет отдельного вопроса про каждый наш маленький шаг.

Чтобы найти ответ в исходном банке, открой его и используй поиск страницы по формулировке вопроса или номеру с точкой. Сначала попробуй ответить сам, затем раскрывай подсказку.

Порядок ответа: объясни смысл своими словами → покажи пример из проекта → назови ограничение → попробуй уточняющий вопрос ментора. 30–60 секунд — ориентир краткого первого ответа, а не запрет подумать.

Если исходная формулировка содержит незнакомый английский термин, сначала переведи его на действие из своего кода. Ответы банка — опора для обсуждения; [пояснения первого круга](first-round.md) помогают начать с человеческого примера.

На неделях 8 и 16 будет короткая репетиция, на 24 — полное пробное интервью. Вопросы продолжения не требуются для завершения основного маршрута.
