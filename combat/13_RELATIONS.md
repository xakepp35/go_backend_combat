# 13. Практика: Как связать данные и не запутаться?

## Задание: история, которую можно объяснить построчно

**3–5 часов:** 45–60 мин на данные и связь, час на JOIN/LEFT JOIN, час на фильтры/счётчики, остаток — удаление, заметки и исправления. Всё в jobflow_lab через psql контейнера; jobflow пока не трогаем.

1. Создай/сверь task_events и сохрани DDL в migrations/002_events.sql. Подготовь три задачи join-a/b/c: два события у a, одно у b, ни одного у c. У событий должны быть разные action, включая changed.
2. До выполнения составь таблицу ожидаемых пар для JOIN и LEFT JOIN. Получи 3 и 4 строки соответственно, ограничив запрос этими ID. Объясни каждую строку и каждый NULL.
3. Выбери только changed-события, сохранив все три задачи. Сравни условие справа в ON и в WHERE; объясни, почему второй вариант может потерять задачи.
4. Посчитай события по задаче через GROUP BY. Сравни count(e.id) и count(*), покажи 0 для c при первом варианте. DISTINCT не используем для сокрытия непонятного размножения строк.
5. Добавь событие неизвестной задачи, получи отказ и проверь отсутствие сироты. На одной из этих тестовых задач покажи ON DELETE CASCADE и судьбу истории. Предложи другой договор удаления для аудита.
6. Сохрани успешные запросы в sql/relations.sql, намеренные отказы — отдельно с пояснениями. В notes/13.md объясни, почему внешний ключ не делает создание задачи и события одной атомарной операцией.

**Приёмка:** набор данных воспроизводим, число строк предсказано, нулевые события отображаются верно, выбор CASCADE обоснован. Открытые SQL-проверки охватывают внешний ключ и базовые JOIN/LEFT JOIN; фильтры ON/WHERE, COUNT и рассуждения ментор проверяет дополнительно.

<details><summary>Если «задачи дублируются»</summary>

Запиши пары задача–событие. Ты просишь строки событий или по одной строке задачи? Исправь форму результата под вопрос, прежде чем добавлять DISTINCT.

</details>

**★ По желанию:** найди задачи без changed-событий через NOT EXISTS. Сравни смысл с LEFT JOIN и фильтром IS NULL; обсудите запрос после того, как можешь предсказать результат.
