# 19. Практика: Пользователь ушёл. Продолжаем работу?

[Карта курса](../course/README.md) · [← Предыдущий урок](18_WORKERS.md) · [Следующий урок →](20_BACKGROUND.md)

Передавай context через API, Service и хранилище. Добавь отмену ожидания и остановку worker-команды без зависания при заполненной очереди. Основное HTTP-приложение должно завершаться через Shutdown.

Проверь отмену до начала, во время ожидания и нормальное завершение. **4–6 часов** включают чтение полного примера остановки. В заметках назови хозяина каждой горутины.

<details><summary>Cancel вызван, но работа продолжается</summary>

Найди место ожидания. Оно должно наблюдать Done или получать context через API библиотеки. Сам вызов cancel не прерывает любой код автоматически.

</details>

На ревью объясни, почему фоновое задание может жить дольше HTTP-запроса, и кто тогда должен его отменить.

**★ По желанию:** добавь отдельный тест остановки при заполненном канале и докажи, что все запущенные работы завершились.
