# 22. Практика: Почему запрос стал медленным?

[Карта курса](../course/README.md) · [← Предыдущий урок](21_OPERATIONS.md) · [Следующий урок →](23_JOB_SEARCH.md)

Возьми запрос незавершённых задач с сортировкой. Подготовь отдельную учебную выборку по `sql/benchmark.sql`, сохрани план до индекса, добавь миграцию и сравни.

Опиши условия, число строк, основные шаги плана и наблюдение. Если индекс не выбран, объясни возможную причину и проверь статистику/размер. **4–6 часов** включают чтение плана и обсуждение.

<details><summary>Где искать первый смысл в большом выводе</summary>

Найди название доступа к tasks, фактическое число строк, фильтр и сортировку. Затем свяжи каждый шаг с WHERE/ORDER BY/LIMIT своего запроса.

</details>

На ревью объясни, почему нельзя выполнять EXPLAIN ANALYZE для произвольного изменения в рабочей базе как безобидный просмотр.

**★ По желанию:** сравни вставку демонстрационных данных с индексом и без него в отдельных временных таблицах.
