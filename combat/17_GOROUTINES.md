# 17. Практика: Можно делать несколько дел одновременно?

[Карта курса](../course/README.md) · [← Предыдущий урок](16_TRANSACTIONS.md) · [Следующий урок →](18_WORKERS.md)

Добавь отдельную демонстрационную команду с двумя горутинами и корректным ожиданием. Затем напиши конкурентный тест memory.Store: несколько добавлений и чтений, после завершения — проверка результата.

Запусти `go test -race ./...` для исправного проекта. Намеренную гонку исследуй в отдельном примере по инструкции. На всё **4–6 часов**.

<details><summary>Потерялась работа после запуска</summary>

Сначала проверь ожидание завершения. Если оно есть, проверь общий доступ и сообщения ошибок. Println внутри горутин может случайно менять расписание и маскировать проблему.

</details>

На ревью объясни отличие конкурентности от параллелизма и покажи, какие данные защищает каждый замок.

**★ По желанию:** сравни последовательную и конкурентную версию задачи с ожиданием, запиши условия эксперимента.
