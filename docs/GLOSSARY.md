# Слова, которые появляются по дороге

Словарь помогает вернуться к смыслу. На первом знакомстве начинай с примера урока. Backend — часть приложения, которая принимает обращения, выполняет правила и работает с данными за пользовательским интерфейсом.

## Урок 01

- **программа** — Описание действий на языке, которое компьютер может выполнить после подготовки инструментами языка.
- **алгоритм** — Упорядоченный способ решить задачу: шаги, выборы и повторения.
- **исходный код** — Текст программы, который мы читаем и редактируем.
- **компилятор** — Инструмент проверки и перевода исходного кода в исполняемую программу.

- **требование** — Конкретное ожидаемое свойство программы, о котором договорились.
- **ТЗ** — Согласованные требования, ограничения и способ приёмки результата.
- **инвариант** — Условие, которое должно сохраняться для допустимого состояния или операции.
- **отладка** — Поиск причины расхождения ожидания и наблюдаемого результата.

[Вернуться к примеру](../student/01_FIRST_PROGRAM.md)

## Урок 02

- **переменная** — Имя для хранящегося значения, которое можно менять в пределах правил типа.
- **тип** — Правила представления значения и допустимых действий над ним.
- **string** — Тип строк: последовательностей байтов; текст обычно записан в UTF-8.
- **int** — Тип целых чисел; точная разрядность зависит от платформы.
- **bool** — Логическое значение true или false.

- **единица измерения** — Смысл числовой величины: например, минуты вместо секунд.
- **нулевое значение** — Начальное значение типа без явного присваивания: 0, пустая строка, false.
- **область видимости** — Участок кода, в котором доступно объявленное имя.

[Вернуться к примеру](../student/02_VALUES.md)

## Урок 03

- **условие** — Выражение с результатом true/false, по которому выбирается действие.
- **if** — Конструкция выбора действий по условию.
- **цикл** — Повторение действий по правилу продолжения.
- **for** — Конструкция циклов Go.

- **защитная проверка** — Отказ до основного действия при нарушении входного условия.
- **граничный случай** — Пример на краю допустимого диапазона или рядом с ним.
- **таблица решений** — Сопоставление сочетаний условий с ожидаемыми действиями.

[Вернуться к примеру](../student/03_DECISIONS.md)

## Урок 04

- **функция** — Именованное действие с параметрами и, при необходимости, результатами.
- **параметр** — Имя и тип входного значения в объявлении функции.
- **аргумент** — Конкретное значение, переданное при вызове функции.
- **return** — Возврат результата и завершение текущего вызова функции.

- **контракт** — Договор о входах, результате, отказах и последствиях операции.
- **предусловие** — Что должно быть верно перед вызовом.
- **постусловие** — Что обещано после успешного выполнения.
- **побочный эффект** — Наблюдаемое действие вне возвращаемого результата: вывод, запись, отправка.
- **декомпозиция** — Разделение задачи на части с ясными обязанностями.

[Вернуться к примеру](../student/04_FUNCTIONS.md)

## Урок 05

- **срез** — Представление последовательности элементов, связанное с нижележащим массивом; имеет длину и вместимость.
- **map** — Соответствие ключей значениям. Порядок обхода не гарантируется.
- **ключ** — Значение, по которому ищут запись в map или различают строку таблицы.
- **CRUD** — Четыре действия: создать, прочитать, изменить, удалить.

[Вернуться к примеру](../student/05_COLLECTIONS.md)

## Урок 06

- **struct** — Тип структуры: значение с именованными полями.
- **метод** — Функция с получателем определённого типа.
- **указатель** — Значение, через которое можно обратиться к существующему значению; получение адреса записывается &.
- **копирование** — Создание отдельного значения. Поля-ссылки при этом могут продолжать ссылаться на общие данные.

[Вернуться к примеру](../student/06_TASK_MODEL.md)

## Урок 07

- **error** — Интерфейс представления ошибки; обычная функция может вернуть его вместе с результатом.
- **nil** — Нулевое значение некоторых типов; в результате error обычно означает отсутствие ошибки.
- **валидация** — Проверка данных на соответствие правилам перед использованием или сохранением.
- **errors.Is** — Проверка соответствия ошибки категории, в том числе через обёртки.

[Вернуться к примеру](../student/07_ERRORS.md)

## Урок 08

- **тест** — Программа, сравнивающая наблюдаемое поведение с выбранным ожиданием.
- **регрессия** — Возвращение ошибки или нарушение ранее работающего поведения после изменения.
- **табличный тест** — Одинаковая процедура проверки для набора именованных случаев.
- **CI** — Автоматическое повторение сборки и проверок после изменений.

[Вернуться к примеру](../student/08_TESTS.md)

## Урок 09

- **модуль** — Набор Go-пакетов с общим go.mod и путём модуля.
- **пакет** — Единица организации и импорта Go-кода, обычно файлы одной директории.
- **internal** — Имя директории, которое ограничивает импорт её пакетов деревом родительской директории.
- **сборка программы** — Выбор конкретных компонентов и их соединение; также словом «сборка» называют компиляцию, смысл уточняется по ситуации.

[Вернуться к примеру](../student/09_ENVIRONMENT.md)

## Урок 10

- **клиент** — Участник взаимодействия, который обращается за действием или данными.
- **сервер** — Участник, принимающий обращения и отвечающий на них.
- **HTTP** — Протокол обмена запросами и ответами между программами.
- **обработчик** — Функция или компонент, выполняемый при подходящем обращении.

[Вернуться к примеру](../student/10_HTTP.md)

## Урок 11

- **API** — Договор о доступных действиях и формате взаимодействия программ.
- **JSON** — Текстовый формат значений: объектов, массивов, строк, чисел, true/false и null.
- **маршрут** — Правило выбора обработчика, например метод и путь HTTP.
- **код ответа** — Число, передающее категорию результата HTTP-запроса.

[Вернуться к примеру](../student/11_API.md)

## Урок 12

- **таблица** — Данные, организованные в строки с общим набором столбцов.
- **строка** — В SQL — одна запись таблицы; в Go string — другой смысл слова.
- **столбец** — Именованное свойство строк таблицы с определённым типом.
- **SQL** — Язык запросов и изменений реляционной базы данных.
- **PRIMARY KEY** — Первичный ключ: уникально различает строки и запрещает NULL в ключевых столбцах.

[Вернуться к примеру](../student/12_SQL.md)

## Урок 13

- **FOREIGN KEY** — Ограничение, связывающее значения с допустимыми значениями другой таблицы.
- **JOIN** — Соединение строк таблиц по условию соответствия.
- **ограничение** — Правило базы для допустимого состояния данных: ключ, NOT NULL, CHECK и другие.
- **связь** — Соответствие между данными, например задача и множество событий её истории.

[Вернуться к примеру](../student/13_RELATIONS.md)

## Урок 14

- **драйвер** — Библиотека взаимодействия программы с конкретной системой, например PostgreSQL.
- **пул соединений** — Ограниченный набор повторно используемых соединений.
- **миграция** — Версионированное изменение схемы базы, сохранённое вместе с проектом.
- **параметр запроса** — Данные, передаваемые в SQL отдельно от текста запроса.

[Вернуться к примеру](../student/14_POSTGRES.md)

## Урок 15

- **интерфейс** — В Go — договор о методах; потребитель может использовать подходящий конкретный тип через этот договор.
- **потребитель** — Код, который вызывает нужное ему поведение другого компонента.
- **реализация** — Конкретный код, выполняющий обещанное поведение.
- **репозиторий** — По контексту: Git-проект или компонент доступа к данным. В Repository приложения имеется в виду второй смысл.

[Вернуться к примеру](../student/15_INTERFACES.md)

## Урок 16

- **транзакция** — Группа изменений базы с фиксацией целиком либо откатом.
- **COMMIT** — Фиксация успешной транзакции.
- **ROLLBACK** — Отмена изменений текущей транзакции.
- **атомарность** — Свойство «всё или ничего» для рассматриваемой операции.

[Вернуться к примеру](../student/16_TRANSACTIONS.md)

## Урок 17

- **горутина** — Независимая работа, которой управляет среда выполнения Go.
- **WaitGroup** — Средство дождаться завершения учтённой группы работ.
- **гонка данных** — Несогласованные конфликтующие обращения к одной памяти, хотя бы одно из которых — запись.
- **Mutex** — Замок для согласования доступа к общим данным.

[Вернуться к примеру](../student/17_GOROUTINES.md)

## Урок 18

- **канал** — Средство передачи значений и согласования между горутинами.
- **worker pool** — Ограниченное число исполнителей, получающих задания из общего источника.
- **очередь** — Ожидающая работа и правило её получения исполнителями.
- **ограничение параллелизма** — Верхняя граница одновременно выполняемых работ.

[Вернуться к примеру](../student/18_WORKERS.md)

## Урок 19

- **context** — Передаваемый через вызовы сигнал отмены, срок и данные области запроса.
- **отмена** — Сигнал прекратить работу; выполняющий код должен его наблюдать.
- **тайм-аут** — Длительность допустимого ожидания, из которой можно установить крайний срок.
- **graceful shutdown** — Согласованная остановка: прекратить приём, завершить/отменить работу, дождаться её и закрыть ресурсы.

## Урок 20

- **состояние** — Сохранённое положение объекта в его жизненном цикле.
- **попытка** — Один запуск работы, завершившийся результатом, ошибкой или прерыванием.
- **retry** — Повтор после ошибки по правилам причин, задержки и предельного числа попыток.
- **идемпотентность** — Повтор одной операции имеет тот же предусмотренный эффект, что и одно её применение.

## Окружение 09 и база 14

- **Образ** — упакованные файлы и настройки запуска приложения; не конкретный работающий процесс.
- **Контейнер** — изолированный экземпляр процесса из образа.
- **Compose** — описание сервисов, сетей, томов и настроек совместного запуска.
- **Volume** — постоянное хранилище Docker, отдельное от изменяемого слоя контейнера. Не резервная копия.
- **Healthcheck** — ограниченная проверка состояния сервиса; успешность зависит от выбранного критерия.
- **Пул соединений** — ограниченный набор переиспользуемых подключений к БД. pgxpool — нативный пул pgx/v5.
- **Миграция** — версионированное изменение схемы. В core Goose/v3 применяет встроенные SQL при старте.
- **go:embed** — директива Go для включения файлов в программу на этапе сборки.
- **Advisory lock** — согласованная блокировка для участников, использующих тот же ключ; не универсальный запрет работы с таблицами.
- **Readiness** — готовность принимать работу, а не просто существование процесса.
- **Expand/contract** — сначала совместимое расширение схемы, затем переход кода/данных и уборка старого договора.

## Следующая глубина 10–15

- **Маршрут** — правило выбора обработчика, например GET /tasks/{id}.
- **Query string** — параметры URL после ?, не сохранённая задача и не тело запроса.
- **DTO** — именованный объект передачи данных через выбранную границу.
- **Порт** — договор, нужный потребителю; адаптер исполняет его конкретным инструментом.
- **Кардинальность результата** — число строк после выбранных соединений и фильтров.
- **LEFT JOIN** — сохраняет строки левой стороны, добавляя NULL справа, если пары нет; последующий WHERE может их убрать.
- **Набор методов** — методы типа, по которым Go определяет соответствие интерфейсу.
- **Внедрение зависимости** — передача нужного исполнителя снаружи, например аргументом конструктора.
