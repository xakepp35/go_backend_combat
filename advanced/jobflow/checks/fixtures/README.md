# Открытые векторы формата

[frames.json](frames.json) содержит полный wire в hex, ожидаемые исходные байты body, связи и признак valid. Это векторы **бинарного слоя**; нулевой ctx допустим при проверке кодека, но pub отклоняет такой workflow.

Покрыты пустое тело, один байт, настоящие нули в конце, 64 нулевых байта, ref/dep, неверный key, усечение и ненулевой padding. Пустой вектор дополнительно закреплён независимым известным BLAKE3-256 в проверке 13. Roundtrip дополняет проверку константных смещений, размера и искажённых входов.

Грейдер копирует векторы в временный проект и проверяет их с этапа 13. Нормативный контракт: [FRAMING](../../docs/FRAMING.md). Fixtures открыты; не меняйте их ради прохождения собственной реализации.
