## Результат

Как сохранить данные вне процесса и воспроизвести схему? Продолжайте тот же репозиторий JobFlow.

**Защищаемое правило:** Схема создаётся из файла; БД сама защищает уникальность ID.

Бюджет: 8–12 часов с подготовкой. Ориентир: 1–2 часа на чтение и план, 5–7 на реализацию, 1–2 на проверки и объяснение. ★ выбирается по оставшемуся времени; для обязательного PASS она не требуется.

## Обязательная часть

1. Создать migrations/001_core.sql с drafts и draft_intents по контракту.
2. Поднять только PostgreSQL; выполнять ручной эксперимент в схеме lesson07.
3. Сохранить CRUD-запросы в sql/01_basics.sql.
4. Показать отказ повторного PRIMARY KEY и проверить оставшееся состояние.

Сохраняйте ранее введённые интерфейсы и обещания. Формальные сигнатуры и крайние случаи доступны в [проверке 07](../checks/07_test.go) и [правилах проверки](../checks/README.md); зависимость инфраструктуры от домена направлена к домену.

## Критерии приёмки

1. Миграция выполняется на пустой схеме.
2. Строка создаётся, читается и изменяется.
3. Настоящий PostgreSQL отклоняет дубликат.

Из корня курса запустите:

```bash
make check LESSON=07 PROJECT=/absolute/path/to/jobflow
```

Команда должна завершиться кодом 0 и PASS обязательных проверок 01–07. Ошибка, пропуск инфраструктуры или отсутствие пакета дают FAIL. Собственные тесты добавляйте рядом с реализацией. Открытые тесты разрешено читать и запускать до сдачи.

## Что сдать

- PR или коммит со всеми обязательными изменениями и README запуска.
- Вывод автоматической проверки с номером этапа и ревизией кода.
- Краткое объяснение инварианта: где проверяется, какой отказ обнаружен, чем подтверждён результат.

## Необязательная ★

Написать отчёт GROUP BY по Kind и объяснить отсутствующие JSON-поля.

Не меняйте обязательный внешний контракт ради ★. В PR опишите дополнительное условие и способ проверки. Результат ★ обсуждается отдельно и не меняет PASS основной части.

## Если застряли

Воспроизведите одну ошибку минимальным входом. Проверьте ожидаемый результат до правки, затем сравните свой участок с [эталоном 07](../reference/07/README.md). Объясните отличие своими словами и повторите проверку без копирования всего проекта.
