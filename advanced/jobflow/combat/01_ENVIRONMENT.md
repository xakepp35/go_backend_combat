## Результат

Как получить проверяемый результат из пустого каталога? Продолжайте тот же репозиторий JobFlow.

**Защищаемое правило:** Другой разработчик воспроизводит запуск из README.

Бюджет: 8–12 часов с подготовкой. Ориентир: 1–2 часа на чтение и план, 5–7 на реализацию, 1–2 на проверки и объяснение. ★ выбирается по оставшемуся времени; для обязательного PASS она не требуется.

## Обязательная часть

1. Скопировать starter в собственный репозиторий с module jobflow.
2. Написать cmd/hello: вывести JobFlow и успешно завершиться.
3. Добавить README с командами и CI для build/vet/test.
4. Сохранить работу в ветке и подготовить PR с ожидаемым результатом.

Сохраняйте ранее введённые интерфейсы и обещания. Формальные сигнатуры и крайние случаи доступны в [проверке 01](../checks/01_test.go) и [правилах проверки](../checks/README.md); зависимость инфраструктуры от домена направлена к домену.

## Критерии приёмки

1. Вывод содержит JobFlow.
2. Проект собирается, vet и test завершаются успешно.
3. Команды воспроизводятся после клонирования.

Из корня курса запустите:

```bash
make check LESSON=01 PROJECT=/absolute/path/to/jobflow
```

Команда должна завершиться кодом 0 и PASS обязательных проверок 01–01. Ошибка, пропуск инфраструктуры или отсутствие пакета дают FAIL. Собственные тесты добавляйте рядом с реализацией. Открытые тесты разрешено читать и запускать до сдачи.

## Что сдать

- PR или коммит со всеми обязательными изменениями и README запуска.
- Вывод автоматической проверки с номером этапа и ревизией кода.
- Краткое объяснение инварианта: где проверяется, какой отказ обнаружен, чем подтверждён результат.

## Необязательная ★

Добавить аргумент имени проекта и проверить пустое значение без внешней CLI-библиотеки.

Не меняйте обязательный внешний контракт ради ★. В PR опишите дополнительное условие и способ проверки. Результат ★ обсуждается отдельно и не меняет PASS основной части.

## Если застряли

Воспроизведите одну ошибку минимальным входом. Проверьте ожидаемый результат до правки, затем сравните свой участок с [эталоном 01](../reference/01/README.md). Объясните отличие своими словами и повторите проверку без копирования всего проекта.
