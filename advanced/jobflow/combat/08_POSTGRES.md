## Результат

Как заменить карту БД с прежним контрактом? Продолжайте тот же репозиторий JobFlow.

**Защищаемое правило:** Данные читаются после открытия независимого подключения.

Бюджет: 8–12 часов с подготовкой. Ориентир: 1–2 часа на чтение и план, 5–7 на реализацию, 1–2 на проверки и объяснение. ★ выбирается по оставшемуся времени; для обязательного PASS она не требуется.

## Обязательная часть

1. Реализовать postgres.Open/Close/Migrate и Repository.
2. Использовать параметризованные SQL-запросы.
3. Перевести известные ошибки драйвера в категории приложения.
4. Проверить независимое подключение и повтор миграции.

Сохраняйте ранее введённые интерфейсы и обещания. Формальные сигнатуры и крайние случаи доступны в [проверке 08](../checks/08_test.go) и [правилах проверки](../checks/README.md); зависимость инфраструктуры от домена направлена к домену.

## Критерии приёмки

1. Второе подключение видит те же байты.
2. Повтор миграции безопасен.
3. Дубликат и отсутствие ID распознаются.

Из корня курса запустите:

```bash
make check LESSON=08 PROJECT=/absolute/path/to/jobflow
```

Команда должна завершиться кодом 0 и PASS обязательных проверок 01–08. Ошибка, пропуск инфраструктуры или отсутствие пакета дают FAIL. Собственные тесты добавляйте рядом с реализацией. Открытые тесты разрешено читать и запускать до сдачи.

## Что сдать

- PR или коммит со всеми обязательными изменениями и README запуска.
- Вывод автоматической проверки с номером этапа и ревизией кода.
- Краткое объяснение инварианта: где проверяется, какой отказ обнаружен, чем подтверждён результат.

## Необязательная ★

Снять EXPLAIN запроса по ID и объяснить роль индекса PRIMARY KEY.

Не меняйте обязательный внешний контракт ради ★. В PR опишите дополнительное условие и способ проверки. Результат ★ обсуждается отдельно и не меняет PASS основной части.

Воспроизведите одну ошибку минимальным входом. Проверьте ожидаемый результат до правки, затем сравните свой участок с [эталоном 08](../reference/08/README.md). Объясните отличие своими словами и повторите проверку без копирования всего проекта.
