# ДЗ 09. Транзакция и намерение события

## Результат

Что происходит, если второй INSERT завершается ошибкой? Продолжайте тот же репозиторий JobFlow.

**Защищаемое правило:** Черновик и его intent сохраняются вместе либо не сохраняется ни один.

Бюджет: 8–12 часов с подготовкой. Ориентир: 1–2 часа на чтение и план, 5–7 на реализацию, 1–2 на проверки и объяснение. ★ выбирается по оставшемуся времени; для обязательного PASS она не требуется.

## Обязательная часть

1. Добавить CreateWithIntent.
2. Оба INSERT выполнять через одну транзакцию.
3. В тестовой схеме вызвать отказ второго INSERT.
4. Проверить откат первого и отсутствие лишнего intent.

Сохраняйте ранее введённые интерфейсы и обещания. Формальные сигнатуры и крайние случаи доступны в [проверке 09](../checks/09_test.go) и [правилах проверки](../checks/README.md); зависимость инфраструктуры от домена направлена к домену.

## Критерии приёмки

1. Успех даёт одно намерение.
2. Отказ второго шага откатывает первый.
3. Конфликт ID не добавляет новое намерение.

Из корня курса запустите:

```bash
make check LESSON=09 PROJECT=/absolute/path/to/jobflow
```

Команда должна завершиться кодом 0 и PASS обязательных проверок 01–09. Ошибка, пропуск инфраструктуры или отсутствие пакета дают FAIL. Собственные тесты добавляйте рядом с реализацией. Открытые тесты разрешено читать и запускать до сдачи.

## Что сдать

- PR или коммит со всеми обязательными изменениями и README запуска.
- Вывод автоматической проверки с номером этапа и ревизией кода.
- Краткое объяснение инварианта: где проверяется, какой отказ обнаружен, чем подтверждён результат.

## Необязательная ★

Смоделировать два изменения одной версии и предложить условный UPDATE с проверкой RowsAffected.

Не меняйте обязательный внешний контракт ради ★. В PR опишите дополнительное условие и способ проверки. Результат ★ обсуждается отдельно и не меняет PASS основной части.

## Если застряли

Воспроизведите одну ошибку минимальным входом. Проверьте ожидаемый результат до правки, затем сравните свой участок с [эталоном 09](../reference/09/README.md). Объясните отличие своими словами и повторите проверку без копирования всего проекта.
