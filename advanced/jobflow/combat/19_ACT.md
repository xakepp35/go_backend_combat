# ДЗ 19. act и право на попытку

[Программа](../course/README.md) · ← [18. Redis Streams и потерянный потребитель](../combat/18_STREAMS.md) · [20. Время и планирование](../combat/20_SCHEDULING.md) →

## Результат

Как конкурентным потребителям получить одну действительную попытку? Продолжайте тот же репозиторий JobFlow.

**Защищаемое правило:** Claim атомарен; чужой token не позволяет записать результат.

Бюджет: 8–12 часов с подготовкой. Ориентир: 1–2 часа на чтение и план, 5–7 на реализацию, 1–2 на проверки и объяснение. ★ выбирается по оставшемуся времени; для обязательного PASS она не требуется.

## Обязательная часть

1. Добавить act с ограниченным числом потребителей.
2. Реализовать атомарный claim через pub.
3. Добавить реестр обработчиков и бюджет.
4. Передавать token и подтверждать Stream после результата.

Сохраняйте ранее введённые интерфейсы и обещания. Формальные сигнатуры и крайние случаи доступны в [проверке 19](../checks/19_test.go) и [правилах проверки](../checks/README.md); зависимость инфраструктуры от домена направлена к домену.

## Критерии приёмки

1. Из восьми claim успешен один.
2. Чужой token отклоняется.
3. Обработчик sum возвращает ожидаемое значение.

Из корня курса запустите:

```bash
make check LESSON=19 PROJECT=/absolute/path/to/jobflow
```

Команда должна завершиться кодом 0 и PASS обязательных проверок 01–19. Ошибка, пропуск инфраструктуры или отсутствие пакета дают FAIL. Собственные тесты добавляйте рядом с реализацией. Открытые тесты разрешено читать и запускать до сдачи.

## Что сдать

- PR или коммит со всеми обязательными изменениями и README запуска.
- Вывод автоматической проверки с номером этапа и ревизией кода.
- Краткое объяснение инварианта: где проверяется, какой отказ обнаружен, чем подтверждён результат.

## Необязательная ★

Добавить собственный детерминированный обработчик без изменения кода запуска.

Не меняйте обязательный внешний контракт ради ★. В PR опишите дополнительное условие и способ проверки. Результат ★ обсуждается отдельно и не меняет PASS основной части.

## Если застряли

Воспроизведите одну ошибку минимальным входом. Проверьте ожидаемый результат до правки, затем сравните свой участок с [эталоном 19](../reference/19/README.md). Объясните отличие своими словами и повторите проверку без копирования всего проекта.
