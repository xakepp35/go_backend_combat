## Результат

Как хранить несколько задач и не перезаписывать данные незаметно? Продолжайте тот же репозиторий JobFlow.

**Защищаемое правило:** Дубликат не перезаписывает запись; чтение не отдаёт изменяемое внутреннее состояние.

Бюджет: 8–12 часов с подготовкой. Ориентир: 1–2 часа на чтение и план, 5–7 на реализацию, 1–2 на проверки и объяснение. ★ выбирается по оставшемуся времени; для обязательного PASS она не требуется.

## Обязательная часть

1. Реализовать memory.New и Create/Get/List/Update/Delete с context.Context.
2. Различать повторное создание и изменение; не создавать запись неявно через Update.
3. Копировать Body на входе и выходе.
4. Возвращать List в устойчивом порядке по ID.

Сохраняйте ранее введённые интерфейсы и обещания. Формальные сигнатуры и крайние случаи доступны в [проверке 03](../checks/03_test.go) и [правилах проверки](../checks/README.md); зависимость инфраструктуры от домена направлена к домену.

## Критерии приёмки

1. Дубликат сохраняет старый Body.
2. Update изменяет, Delete удаляет запись.
3. Изменение результата Get не меняет хранилище.

Из корня курса запустите:

```bash
make check LESSON=03 PROJECT=/absolute/path/to/jobflow
```

Команда должна завершиться кодом 0 и PASS обязательных проверок 01–03. Ошибка, пропуск инфраструктуры или отсутствие пакета дают FAIL. Собственные тесты добавляйте рядом с реализацией. Открытые тесты разрешено читать и запускать до сдачи.

## Что сдать

- PR или коммит со всеми обязательными изменениями и README запуска.
- Вывод автоматической проверки с номером этапа и ревизией кода.
- Краткое объяснение инварианта: где проверяется, какой отказ обнаружен, чем подтверждён результат.

## Необязательная ★

Добавить пакетное обновление с результатом для каждого ID и объяснить выбранную атомарность.

Не меняйте обязательный внешний контракт ради ★. В PR опишите дополнительное условие и способ проверки. Результат ★ обсуждается отдельно и не меняет PASS основной части.

## Если застряли

Воспроизведите одну ошибку минимальным входом. Проверьте ожидаемый результат до правки, затем сравните свой участок с [эталоном 03](../reference/03/README.md). Объясните отличие своими словами и повторите проверку без копирования всего проекта.
