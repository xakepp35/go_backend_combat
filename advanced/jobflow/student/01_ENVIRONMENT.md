# 01. Инженерная задача и окружение

[Программа](../course/README.md) · [02. Типы, функции и модель задачи](../student/02_GO_MODEL.md) →

**Место в проекте:** месяц 1, Старт и язык Go. Занятие: 50 минут + 10 минут резерва. ДЗ: 8–12 часов, включая подготовку; ★ добровольна.

## Задача недели

Как получить проверяемый результат из пустого каталога?

**Инвариант:** Другой разработчик воспроизводит запуск из README.

**Перед встречей:** Рабочий starter; знание переменных, условий, циклов и функций на другом языке.

Инструменты недели: Go toolchain, терминал, Git, CI.

## Разбор

Начинаем с результата: команда печатает JobFlow и завершается с кодом 0. До выбора папок назовите вход, результат и ошибку. Фраза «работает в IDE» ещё не задаёт воспроизводимого критерия.

go.mod задаёт модуль, package main и func main — точку входа команды. go run собирает и запускает пакет; go build создаёт исполняемый файл. Один пакет может состоять из нескольких файлов одной директории.

pwd показывает рабочий каталог, ls — содержимое, cd меняет каталог. Git status и diff позволяют проверить изменения перед коммитом. Для начала достаточно короткой ветки и PR. CI повторяет build, vet и test на чистой машине; базы и брокеры сегодня не нужны.

## Опорный фрагмент

Фрагмент показывает основную операцию. Имена из окружающего кода смотрите в исходнике этапа: это не отдельная готовая программа.

```bash
go run ./cmd/hello
go build ./...
go vet ./...
go test ./...
```

## Практика на встрече

1. Назовите вход, результат и защищаемое правило для операции недели.
2. Реализуйте первый обязательный пункт [домашнего задания](../combat/01_ENVIRONMENT.md). До запуска предскажите результат.
3. Воспроизведите ошибку: Команду запускают вне корня модуля и исправляют исходник вместо проверки pwd.
4. Исправьте причину и объясните, какое наблюдение теперь подтверждает правило.

## Самопроверка

Почему запуск из IDE ещё не доказывает воспроизводимость?

<details>
<summary>Разбор ответа</summary>

IDE может скрывать рабочую директорию и локальную конфигурацию; нужны команды из чистого checkout.

</details>

Проверьте следующие ситуации до сдачи:

1. Вывод содержит JobFlow.
2. Проект собирается, vet и test завершаются успешно.
3. Команды воспроизводятся после клонирования.

## Самостоятельная работа

Продолжайте свой JobFlow по [ДЗ 01](../combat/01_ENVIRONMENT.md). Оценка опирается на обязательный контракт; творческая часть не нужна следующему этапу. Открывайте эталон после собственной попытки и сравнивайте причины решений, а затем меняйте решение под новое условие.
