# 05. Пакеты и границы зависимостей

[Программа](../course/README.md) · ← [04. Ошибки, валидация и тесты](../student/04_ERRORS_TESTS.md) · [06. HTTP как граница приложения](../student/06_HTTP.md) →

**Место в проекте:** месяц 2, Границы приложения и данные. Занятие: 50 минут + 10 минут резерва. ДЗ: 8–12 часов, включая подготовку; ★ добровольна.

## Задача недели

Как заменить память БД без переписывания правил задачи?

**Инвариант:** Прикладной сервис зависит от поведения, требуемого от хранилища.

**Перед встречей:** Обязательные проверки этапа 04 проходят в вашем репозитории. Повторите его API и ошибку, которую он уже обнаруживает.

Инструменты недели: Пакеты, интерфейсы потребителя.

## Разбор

Проследите Create от вызывающего кода к хранилищу, затем проследите импорты. Вызов во время исполнения идёт в адаптер, но исходный код app не должен импортировать memory или pgx.

Repository объявлен рядом с потребителем — приложением. Реализация удовлетворяет интерфейсу неявно, если имеет нужные методы. Не добавляйте методы только потому, что их умеет конкретный драйвер.

main создаёт зависимости и передаёт их в конструктор. Validate не читает окружение и не открывает подключения. internal ограничивает импорт извне; Go не требует обязательного pkg или единственного стандартного дерева проекта.

## Опорный фрагмент

Фрагмент показывает основную операцию. Имена из окружающего кода смотрите в исходнике этапа: это не отдельная готовая программа.

```go
type Repository interface {
    Create(context.Context, task.Task) error
    Get(context.Context, string) (task.Task, error)
}
service := app.New(memory.New())
```

## Практика на встрече

1. Назовите вход, результат и защищаемое правило для операции недели.
2. Реализуйте первый обязательный пункт [домашнего задания](../combat/05_BOUNDARIES.md). До запуска предскажите результат.
3. Воспроизведите ошибку: app сам создаёт memory.Repository, поэтому тест не может подставить spy.
4. Исправьте причину и объясните, какое наблюдение теперь подтверждает правило.

## Самопроверка

Где объявить интерфейс, нужный только одному потребителю?

<details>
<summary>Разбор ответа</summary>

Рядом с этим потребителем, с необходимыми ему методами.

</details>

Проверьте следующие ситуации до сдачи:

1. Сервис использует переданную реализацию.
2. Невалидный ввод не пересекает границу записи.
3. Домен не импортирует драйверы и HTTP.

## Самостоятельная работа

Продолжайте свой JobFlow по [ДЗ 05](../combat/05_BOUNDARIES.md). Оценка опирается на обязательный контракт; творческая часть не нужна следующему этапу. Открывайте эталон после собственной попытки и сравнивайте причины решений, а затем меняйте решение под новое условие.
