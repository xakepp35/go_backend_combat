## Задача недели

Как хранить несколько задач и не перезаписывать данные незаметно?

**Инвариант:** Дубликат не перезаписывает запись; чтение не отдаёт изменяемое внутреннее состояние.

**Перед встречей:** Обязательные проверки этапа 02 проходят в вашем репозитории. Повторите его API и ошибку, которую он уже обнаруживает.

Инструменты недели: map, slice, методы, указатели.

## Разбор

Карта связывает ID с Task. value, ok := items[id] отличает отсутствие ключа от найденного zero value. Create сначала проверяет наличие ключа; Update изменяет существующий. Для отсутствующего ID возвращаем ошибку. Параметр context.Context пока передаём из context.Background(); отмену подробно разберём на уроке 11.

Копирование структуры со срезом копирует описание среза, но оставляет общий массив. Если Get возвращает внутренний Body напрямую, клиент меняет хранилище без Update. На входе и выходе копируем изменяемые данные.

Методы хранилища используют указатель, потому что работают с его состоянием. Указатель не обеспечивает безопасность конкурентных вызовов. Синхронизация будет отдельной темой. List сортируем по ID, чтобы результаты примеров не зависели от порядка обхода map.

## Опорный фрагмент

Фрагмент показывает основную операцию. Имена из окружающего кода смотрите в исходнике этапа: это не отдельная готовая программа.

```go
value, ok := items[id]
if !ok { return task.Task{}, task.ErrNotFound }
value.Body = append([]byte(nil), value.Body...)
return value, nil
```

## Практика на встрече

1. Назовите вход, результат и защищаемое правило для операции недели.
2. Реализуйте первый обязательный пункт [домашнего задания](../combat/03_MEMORY_CRUD.md). До запуска предскажите результат.
3. Воспроизведите ошибку: Мутация result.Body после Get портит сохранённую задачу.
4. Исправьте причину и объясните, какое наблюдение теперь подтверждает правило.

Почему копия Task не всегда является независимой копией Body?

Проверьте следующие ситуации до сдачи:

1. Дубликат сохраняет старый Body.
2. Update изменяет, Delete удаляет запись.
3. Изменение результата Get не меняет хранилище.
