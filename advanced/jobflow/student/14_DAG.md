# 14. DAG и принятие workflow

**Место в проекте:** месяц 4, Бинарный поток и доставка. Занятие: 50 минут + 10 минут резерва. ДЗ: 8–12 часов, включая подготовку; ★ добровольна.

## Задача недели

Чем существование задачи отличается от готовности к запуску?

**Инвариант:** Принятый граф не содержит циклов и не меняет связи после отправки.

**Перед встречей:** Обязательные проверки этапа 13 проходят в вашем репозитории. Повторите его API и ошибку, которую он уже обнаруживает.

Инструменты недели: DFS, UUIDv7, SQL-транзакция.

## Разбор

Ребро task → dependency означает ожидание успешной зависимости. Отсутствие рёбер даёт готовность по графу, но не отменяет ограничения времени и выдачу полномочий исполнителю.

Локальный ref содержит младшие 64 бита UUID внутри workflow. Сначала строим отображение и отклоняем коллизии. dep содержит полный UUIDv7 уже принятой задачи другого workflow. Все локальные ссылки разрешаются внутри отправленного закрытого набора.

DFS с цветами «не посещали / в текущем пути / завершили» обнаруживает цикл. Проверенный граф сохраняется одной транзакцией. Повтор тех же ID и входов идемпотентен, изменение — конфликт. После принятия связи неизменяемы; внешняя зависимость не может задним числом сослаться на новый workflow.

## Опорный фрагмент

Фрагмент показывает основную операцию. Имена из окружающего кода смотрите в исходнике этапа: это не отдельная готовая программа.

```go
if color[id] == 1 { return task.ErrInvalid }
if color[id] == 2 { return nil }
color[id] = 1
// Обойти зависимости.
color[id] = 2
```

## Практика на встрече

1. Назовите вход, результат и защищаемое правило для операции недели.
2. Реализуйте первый обязательный пункт [домашнего задания](../combat/14_DAG.md). До запуска предскажите результат.
3. Воспроизведите ошибку: Один visited не отличает завершённую вершину от вершины текущего пути.
4. Исправьте причину и объясните, какое наблюдение теперь подтверждает правило.

## Самопроверка

Почему задача без локальных рёбер может быть не готова?

<details>
<summary>Разбор ответа</summary>

Остаются внешние dep, время, срок и состояние попытки.

</details>

Проверьте следующие ситуации до сдачи:

1. Цепочка и ромб принимаются.
2. Цикл и неизвестный ref отклоняются.
3. Повтор не создаёт новый workflow.

## Самостоятельная работа

Продолжайте свой JobFlow по [ДЗ 14](../combat/14_DAG.md). Оценка опирается на обязательный контракт; творческая часть не нужна следующему этапу. Открывайте эталон после собственной попытки и сравнивайте причины решений, а затем меняйте решение под новое условие.
