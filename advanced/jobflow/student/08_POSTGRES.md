## Задача недели

Как заменить карту БД с прежним контрактом?

**Инвариант:** Данные читаются после открытия независимого подключения.

**Перед встречей:** Обязательные проверки этапа 07 проходят в вашем репозитории. Повторите его API и ошибку, которую он уже обнаруживает.

Инструменты недели: pgxpool, context, SQL-адаптер.

## Разбор

Пул создаётся один раз на процесс, проверяется Ping и закрывается при завершении. Создавать пул на каждый запрос дорого и мешает ограничению ресурсов. context.Context передаётся каждому вызову драйвера.

Значение ID передаётся как параметр $1 отдельно от SQL. ErrNoRows переводится в ErrNotFound; уникальный конфликт — в ErrConflict. Остальные ошибки не маскируются как отсутствие данных. Rows закрывается, после обхода проверяется rows.Err.

Мигратор применяет файлы по порядку, сохраняет имя и checksum. Повторный запуск пропускает применённый файл, а изменение его содержимого возвращает ошибку. SHA-256 файла миграции не заменяет BLAKE3 тела задачи: это разные контракты.

## Опорный фрагмент

Фрагмент показывает основную операцию. Имена из окружающего кода смотрите в исходнике этапа: это не отдельная готовая программа.

```go
store, err := postgres.Open(ctx, dsn)
if err != nil { return err }
defer store.Close()
if err := store.Migrate(ctx, "migrations"); err != nil { return err }
service := app.New(store)
```

## Практика на встрече

1. Назовите вход, результат и защищаемое правило для операции недели.
2. Реализуйте первый обязательный пункт [домашнего задания](../combat/08_POSTGRES.md). До запуска предскажите результат.
3. Воспроизведите ошибку: Тест проверяет исходную структуру вместо SELECT из БД.
4. Исправьте причину и объясните, какое наблюдение теперь подтверждает правило.

## Самопроверка

Как проверить persistence без чтения из той же Go-переменной?

<details>
<summary>Разбор ответа</summary>

Открыть второе независимое подключение и получить записанную задачу.

</details>

Проверьте следующие ситуации до сдачи:

1. Второе подключение видит те же байты.
2. Повтор миграции безопасен.
3. Дубликат и отсутствие ID распознаются.

## Самостоятельная работа

Продолжайте свой JobFlow по [ДЗ 08](../combat/08_POSTGRES.md). Оценка опирается на обязательный контракт; творческая часть не нужна следующему этапу. Открывайте эталон после собственной попытки и сравнивайте причины решений, а затем меняйте решение под новое условие.
