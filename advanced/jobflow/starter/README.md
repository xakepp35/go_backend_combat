# Мой JobFlow

Начало ДЗ 01. Скопируйте **содержимое** этой папки, включая `.github` и `.gitignore`, в собственный репозиторий. Module path `jobflow` нужен открытым проверкам. Дальше развивайте этот же проект, не копируйте будущие эталоны.

## Подготовка

Установите Go 1.27.2 и Git. Для первого этапа не нужны базы и брокеры. Откройте терминал в папке с `go.mod`.

```bash
go run ./cmd/hello
go build ./...
go vet ./...
go test ./...
```

Сейчас выводится TODO. В ДЗ 01 измените программу по контракту, заполните README своими командами и создайте PR. Проверка первого этапа должна сначала падать, затем проходить после исправления.

Из корня **курса**, который хранится отдельно:

```bash
make check LESSON=01 PROJECT=/absolute/path/to/this/project
```

## Заполнить в ДЗ 01

- Проверенные команды запуска и проверки.
- Требования к окружению.
- Ссылка на PR и версия выполненного этапа.
