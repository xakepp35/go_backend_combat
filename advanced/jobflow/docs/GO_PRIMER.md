# Go: опорный материал первых недель

Для разработчика с опытом другого языка. Читайте разделы по мере прохождения уроков 01–05; набирать весь справочник до первой встречи не требуется. Фрагменты ниже используют имена из окружающего кода. Работающий код каждой недели находится в reference/NN.

## 01. Модуль и команда

`go.mod` задаёт путь модуля `jobflow`. Путь импорта собственного пакета складывается из него и каталога: `jobflow/internal/task`. В одном каталоге файлы имеют общий package. Команда использует package main и функцию main без параметров.

```go
package main

import "fmt"

func main() {
    fmt.Println("JobFlow")
}
```

Из каталога с go.mod: `go run ./cmd/hello`, `go build ./...`, `go vet ./...`, `go test ./...`. Три точки означают пакеты ниже текущего каталога. Неиспользуемые импорты и локальные переменные — ошибки компиляции. Форматирование: `gofmt -w path/to/file.go`.

## 02. Значения, типы и функции

```go
var count int         // 0
name := "echo"        // string
var body []byte       // nil slice
body = []byte("data")
const limit = 128
```

`:=` объявляет локальную переменную, `=` присваивает существующей. Неинициализированные значения получают zero value. Строка — неизменяемая последовательность байтов; её длина в байтах может отличаться от количества символов Unicode. В Task тело — `[]byte`, оно может содержать нули и не обязано быть текстом.

```go
func add(a, b int) int { return a + b }

func lookup(id string) (string, bool) {
    if id == "a" { return "found", true }
    return "", false
}

value, ok := lookup("a")
```

Тип результата записывается после параметров. Возвращаемых значений может быть несколько. `_` явно отбрасывает результат; ошибка отбрасывается только с понятным объяснением.

## 03. Условия, циклы и коллекции

Условия требуют bool. Скобки вокруг условия не нужны; фигурные скобки нужны. Единственное ключевое слово цикла — for.

```go
if len(body) == 0 {
    // Пустое тело допустимо; отдельно проверяем ID и Kind.
} else {
    // Есть байты.
}
for i := 0; i < 3; i++ { fmt.Println(i) }
for i, b := range body { fmt.Println(i, b) }
```

Срез описывает участок массива. `len` — число доступных элементов, `cap` — вместимость. Индекс вне len вызывает панику. `append` может создать новый массив, поэтому сохраняйте возвращённый срез.

```go
values := []int{1, 2}
values = append(values, 3)
copyOfValues := append([]int(nil), values...)
```

Карта создаётся до записи. Чтение даёт значение и необязательный признак наличия. Порядок обхода не определён; для устойчивого List отсортируйте IDs.

```go
items := make(map[string]int)
items["a"] = 3
value, exists := items["missing"] // 0, false
delete(items, "a")
```

Структура объединяет поля. `&value` получает адрес, `*pointer` разыменовывает. Метод с pointer receiver может менять структуру. Получение указателя не делает совместный доступ безопасным.

```go
type Counter struct { Value int }
func (c *Counter) Inc() { c.Value++ }

c := Counter{}
c.Inc()
```

Копия структуры с полем Body []byte по-прежнему разделяет массив Body. Чтобы Get не позволял менять хранилище, скопируйте изменяемые поля. В Go без unsafe ошибка индекса приводит к панике с проверкой границ, а не к произвольной записи за пределы памяти.

## 04. Ошибки и тесты

Успех обозначается nil error. Обычно проверка располагается сразу после операции. `%w` сохраняет причину для errors.Is; сравнивать текст ошибки как контракт ненадёжно.

```go
var ErrInvalid = errors.New("invalid task")

func validate(id string) error {
    if id == "" { return fmt.Errorf("%w: empty id", ErrInvalid) }
    return nil
}

if err := validate(""); err != nil {
    if errors.Is(err, ErrInvalid) { /* ошибка входа */ }
}
```

Файл теста заканчивается `_test.go`; функция начинается с Test и принимает *testing.T. Таблица случаев помогает явно записать нормальный и ошибочный вход.

```go
func TestValidate(t *testing.T) {
    for _, tc := range []struct {
        name string
        id string
        bad bool
    }{{"empty", "", true}, {"valid", "a", false}} {
        t.Run(tc.name, func(t *testing.T) {
            err := validate(tc.id)
            if (err != nil) != tc.bad { t.Fatalf("unexpected error: %v", err) }
        })
    }
}
```

`defer` выполняется при выходе из функции. Типичные применения: освободить mutex, закрыть rows, откатить незавершённую транзакцию. defer внутри длинного цикла откладывает освобождение до выхода из всей функции — чаще нужен отдельный вызов или явное Close.

## 05. Пакеты и интерфейсы

Имя с большой буквы экспортируется из пакета. Интерфейс задаёт методы, необходимые потребителю. Реализация удовлетворяет ему неявно; отдельное implements не пишется.

```go
type Reader interface {
    Get(context.Context, string) (task.Task, error)
}
type Service struct { reader Reader }
func New(reader Reader) *Service { return &Service{reader: reader} }
```

Точная Repository курса включает CRUD; сокращённый Reader выше показывает принцип. Domain task не импортирует драйвер. main создаёт конкретный адаптер и передаёт его приложению. Если Get объявлен на *Store, передаётся указатель на Store.

`context.Context` передаётся первым параметром операции. В раннем примере используйте context.Background(); в HTTP — request.Context(). Наблюдение отмены, сроки и владение горутинами подробно изучаются на уроке 11.

## Как читать ошибку компиляции

1. Найдите первый файл и строку, указанные компилятором.
2. Назовите ожидаемый и фактический типы. Указатель и значение могут иметь разные наборы методов.
3. Проверьте package, import и корень модуля.
4. Исправьте одну причину и повторите сборку.
