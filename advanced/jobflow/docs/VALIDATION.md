## Повторить

Из корня курса; Go должен быть доступен через PATH или переменную GO:

```bash
make validate
make check-all
make check-mutants
make smoke
python3 tools/coursecheck.py --lesson 24 --project reference/24 --fuzz
```

`check-all` использует общую изолированную инфраструктуру и отдельные тестовые данные для каждого этапа. `smoke` создаёт собственный Compose-проект, проверяет три DAG и ret, затем удаляет свои контейнеры и тома. Для проверки retention smoke меняет время только в собственной тестовой БД; час ожидания не требуется.

## Практические пределы

Проверки подтверждают перечисленные контракты на локальном учебном окружении. Краткая fuzz-сессия и 97,4% покрытия не доказывают отсутствие всех ошибок. Нагрузочное и длительное эксплуатационное испытание в выпуск не входят. Система выполняет зарегистрированные кооперативные Go-обработчики; counter получает защиту эффекта от своего SQL ledger. Остальные гарантии и пределы описаны в [PROJECT](PROJECT.md).
